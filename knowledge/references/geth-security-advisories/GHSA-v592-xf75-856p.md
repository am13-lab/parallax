# GHSA-v592-xf75-856p: Ethash DAG generation bug can cause miners to create invalid PoW

| Field | Value |
|---|---|
| GHSA | [GHSA-v592-xf75-856p](https://github.com/ethereum/go-ethereum/security/advisories/GHSA-v592-xf75-856p) |
| CVE | CVE-2020-26240 |
| Severity | medium |
| Published | 2020-11-24 |
| Updated | 2020-11-24 |
| CWE | none listed |

## Classification (ours)

- P2P-related: NO
- Protocol surface: mining/PoW
- Confidence: high
- Rationale: Ethash DAG generation bug causes miners to compute invalid PoW; affects miners only.

## Affected versions

- `github.com/ethereum/go-ethereum`: vulnerable `< 1.9.24`, patched `>= 1.9.24`

## Description (verbatim from advisory)

### Impact
An ethash mining DAG generation flaw in Geth could cause miners to erroneously calculate PoW in an upcoming epoch (estimated early January, 2021). This happened on the ETC chain on 2020-11-06. This issue is relevant only for miners, non-mining nodes are unaffected.

### Patches
This issue is also fixed as of 1.9.24. Thanks to @slavikus for bringing the issue to our attention and writing the fix. 

### Workarounds
This PR implements a patch: https://github.com/ethereum/go-ethereum/pull/21793
